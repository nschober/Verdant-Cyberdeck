# Recorded verification evidence

These reviewed files record the initial local installation before the Verdant rename. They are historical evidence, not results from GitHub Actions or another host. Failed or unavailable hardware checks are retained. No Pwnagotchi configuration, preservation hashes, private keys, captures or learned data is included.

The current portable-suite result is recorded separately after repository preparation. A skipped host-manifest check on a clean clone is expected; it is not proof that an existing installation is unchanged. Workflow execution on GitHub remains unverified until a remote run completes.

Trailing whitespace in archived text logs is normalized for source control; the original local logs remain untouched.
